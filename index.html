CHA2A

did:cha2a

A registry-mediated DID method for agentic identity and software source attestation — specified openly, with a byte-stable conformance suite.

Specification

did-method-cha2a.md — v1.1.0 Method syntax and ABNF, all four DID operations (Create / Read / Update / Deactivate), DID Document structure and discovery, security and privacy considerations, and a conformance surface with test vectors.

Conformance suite

wwumit/cha2a-conformance Fixtures, two independent reference verifiers (Python and Node.js, parity-checked), pinned by MANIFEST.sha256 for offline re-verification. Six gates, 68 vectors.

Status

  • Draft specification, under review for registration in the W3C DID Extensions registry (PR #744).
  • Reference implementation running at compliancehub.cn — discovery at /.well-known/cha2a, resolution at /api/v1/did/<did>.
